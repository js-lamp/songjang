💾 데이터 백업 · 복원 (기기 간 공유)

PC에서 송장을 올린 뒤 JSON 파일로 내보내기 → 카톡으로 폰에 전송 → 폰에서 불러오기로 동일한 데이터 복원.

☁️ 클라우드 동기화 (Firebase)

한 번 설정하면 PC↔폰 자동 공유. 매번 파일 주고받기 안 해도 됨.

🔧 Firebase 설정 방법 (최초 1회)
1. console.firebase.google.com 접속 → Google 로그인
2. "프로젝트 추가" → 이름 입력 → 애널리틱스 끄기 → 만들기
3. 왼쪽 메뉴 빌드 → Realtime Database → "데이터베이스 만들기"
4. 위치 = asia-southeast1, 보안규칙 = "테스트 모드" → 사용 설정
5. 상단 DB URL 복사 (https://...firebasedatabase.app/) → 아래에 붙여넣기 → "연결"

💡 URL은 본인만 알면 외부 접근 안 됨. 영업사원에게도 같은 URL 공유하면 모두 동일 데이터를 봄.
💡 연결되면 송장 올릴 때 자동으로 클라우드에 올라가고, 다른 기기 접속 시 자동으로 받음
